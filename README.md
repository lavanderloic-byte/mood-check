# 情绪自评（PHQ-9）

适合手机访问的静态网页。9 题均以「过去两周」为回忆期，按 0–3 分计分，总分 0–27 分。结果仅供筛查参考，不能作为诊断。第 9 题只要选择 1–3 分，就会显示单独的安全提示。

## 使用

直接打开 `index.html`，或将本目录发布为 GitHub Pages。页面不需要后端、账号或第三方脚本。答案仅在浏览器内存中计算，刷新即清空。

## 计分

| 总分 | 症状程度 |
| --- | --- |
| 0–4 | 极轻微或没有 |
| 5–9 | 轻度 |
| 10–14 | 中度 |
| 15–19 | 中重度 |
| 20–27 | 重度 |

总分 ≥10 分时提示寻求专业评估；第 9 题任何非零答案均提示优先关注安全。问卷说明与计分依据：[PHQ Screeners](https://www.phqscreeners.com/)。

运行计分测试：`npm test`。
